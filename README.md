## 현재 상태 분석

BMI 23.2로 숫자상 정상이지만, 지방이 배·가슴에 몰려 있고 팔다리가 긴 체형은 전형적인 **스키니팻(마른 비만)** 패턴이다. 이 체형의 핵심 문제는 "살을 빼야 하는 것"이 아니라 **근육량이 부족한 것**이다. 무작정 굶어서 감량하면 팔다리는 더 앙상해지고 가슴·배 지방은 마지막까지 남아서 오히려 거미형이 심해진다.

**결론: 다이어트가 아니라 바디 리컴포지션(근육 ↑ + 체지방 ↓)이 답.**

## 여유증 vs 가슴 지방, 어떻게 구분하나

- **가성 여유증(지방)**: 가슴 전체가 말랑말랑하고, 체지방이 빠지면 같이 빠짐. 스키니팻 남성에게 흔함.
- **진성 여유증(유선조직)**: 유두 바로 아래에 단단한 원반 모양 멍울이 만져짐. 누르면 통증이 있기도 함. 체지방이 10~12%까지 내려가도 유두 주변이 볼록하게 남음.

계획대로 체지방을 12% 이하로 낮췄는데도 유두 아래가 단단하게 남아 있으면 진성 여유증 가능성이 높다. 그때는 **유방외과/성형외과에서 초음파 검사**를 받으면 확실히 알 수 있다 (검사 자체는 언제든 받을 수 있으니, 궁금하면 지금 받아도 됨). 진성이라면 수술(지방흡입+유선제거)로 해결하는 게 일반적이고, 운동으로는 유선조직이 없어지지 않는다.

## 목표 (선 커팅 → 후 벌크업 전략)

가슴·배 지방을 먼저 빼고 싶으므로 **커팅부터 시작**한다. 장점: ①빠르게 눈에 보이는 변화 ②여유증 여부를 3~4개월 안에 확인 가능 ③가벼운 몸으로 벌크업 시작. 단, 커팅 중에도 **웨이트는 무조건 병행**해야 한다. 웨이트 없이 감량하면 근육까지 빠져서 거미형이 심해진다.

| 단계 | 목표 | 기간 |
|------|------|------|
| 1단계: 커팅 | 77kg → 71~72kg (주 0.5kg 감량), 체지방 12~14% → **여유증 판별** | 0~3.5개월 |
| 2단계: 린매스업 | 71~72kg → 78~80kg 천천히 증량 (월 +0.5~1kg), 근육량 집중 | 3.5~11개월 |
| 3단계: 최종 커팅 | 체지방 10~12%로 마무리 → 바프 촬영 | 11~13개월 |

"빠르게"의 현실적인 한계: 주 0.5~0.7kg 이상 감량하면 근손실이 커져서 결국 손해다. 가슴·배 지방은 **가장 마지막에 빠지는 부위**라서 첫 한 달은 얼굴·팔부터 빠지는 게 정상 — 여기서 포기하지 말 것.

## 식단 (1단계: 커팅 기준)

- **기초대사량(BMR)**: 약 1,780kcal
- **활동대사량(TDEE)**: 약 2,600~2,700kcal (주 4~5회 운동 기준)
- **목표 섭취**: **2,000~2,100kcal** (하루 -500~600kcal 적자 → 주 0.5kg 감량)
- **단백질**: **160g/일** (체중 × 2g 이상) — 커팅 중 근손실 방어의 핵심. 닭가슴살, 계란, 소고기, 그릭요거트, 프로틴 쉐이크
- **탄수화물**: 180~200g (운동 전후에 몰아서)
- **지방**: 50~55g

원칙:
1. 단백질 목표만은 무슨 일이 있어도 채운다 (커팅 중엔 더더욱)
2. 액상 칼로리(음료수, 술) 끊기 — 술은 특히 여유증·복부지방 악화 요인
3. 주 1회 치팅밀 OK, 치팅데이는 NO
4. 2주간 체중 변화 없으면 -100kcal 추가 또는 유산소 10분 추가
5. 벌크업 전환(2단계) 시 2,700~2,800kcal로 올리고 단백질 유지

## 운동 루틴 (주 4회, 2분할 상하체)

거미형 체형은 **어깨·등·가슴 상부**를 키워야 실루엣이 극적으로 바뀐다. 어깨가 넓어지면 상대적으로 허리·배가 얇아 보이는 효과.

### DAY 1 & 3 — 상체
| 운동 | 세트×횟수 | 포인트 |
|------|-----------|--------|
| 인클라인 벤치프레스 | 4×8~10 | 가슴 상부 최우선 (가슴 처짐 커버) |
| 오버헤드 프레스 | 4×8~10 | 어깨 프레임 |
| 랫풀다운 / 턱걸이 | 4×8~12 | 역삼각 실루엣 |
| 사이드 레터럴 레이즈 | 4×12~15 | 어깨 옆태 |
| 케이블 크로스오버(하이→로우) | 3×12~15 | 가슴 하부 라인 정리 |
| 페이스풀 | 3×15 | 어깨 후면 + 자세 교정 |

### DAY 2 & 4 — 하체 + 코어
| 운동 | 세트×횟수 | 포인트 |
|------|-----------|--------|
| 스쿼트 | 4×8~10 | 전신 대사량의 핵심 |
| 루마니안 데드리프트 | 4×8~10 | 후면 사슬 |
| 레그프레스 | 3×10~12 | |
| 레그컬 | 3×12 | |
| 행잉 레그레이즈 | 3×12~15 | 복근 |
| 플랭크 | 3×60초 | |

- **커팅기 유산소**: 웨이트 후 경사 걷기(속도 5.5~6, 경사 8~10) 30~40분 × 주 4회. 달리기보다 근손실이 적고 지방 연소에 효율적.
- 커팅 중에도 중량을 최대한 유지하려고 버텨라. 중량 유지 = 근육 유지 신호다.
- 팔다리가 길면 스쿼트·벤치 가동범위가 커서 처음엔 중량이 잘 안 늘어난다. **정상이니 조급해하지 말 것.** 대신 가동범위가 큰 만큼 근육 자극은 더 좋다.
- 가슴 지방만 빼는 운동은 존재하지 않는다(부분감량 불가). 윗몸일으키기 100개보다 식단 적자가 뱃살을 뺀다. 가슴 운동은 지방을 빼는 게 아니라 **지방 밑에 근육을 채워서** 라인을 만드는 것.
